Official public product page for **UpscaleKit**, a browser-based AI image upscaler that enlarges and unblurs photos.

## About the product

UpscaleKit is an AI image upscaler that runs in the browser. You upload a photo, choose an output size, and compare results across two upscaling models — SeedVR2 and Crystal — before spending credits. Each export is priced by output size, and credits are sold in one-time packs starting at $5.00. There is no subscription, credits do not expire, and failed generations are refunded.

Outputs are AI-generated approximations. The tool reconstructs plausible detail; it cannot recover information that was never present in the original file.

## About this repository

This repository publishes the official English product page and brand information for UpscaleKit. It contains a static `index.html`, the screenshots used on that page, and this README.

It does **not** contain the product's source code, generation pipeline, deployment configuration or user data. The application repository is private. Nothing in this repository implies that UpscaleKit is open source.
